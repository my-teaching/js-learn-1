# JavaScript: типы данных, преобразования и базовая арифметика

## 1. Зачем вообще нужны типы данных

Любое значение в JavaScript имеет тип. Тип определяет, что хранит значение и какие операции с ним имеют смысл.

Например:

```js
const price = 500;       // number
const title = "Книга";   // string
const isPaid = false;    // boolean
```

JavaScript относится к языкам с **динамической типизацией**: тип связан со значением, а не закреплён за переменной навсегда.

```js
let value = 10;
value = "десять";
value = true;
```

Такой код допустим. Это удобно, но одновременно требует аккуратно следить за тем, какие значения участвуют в выражениях.

---

## 2. Какие типы есть в JavaScript

В языке есть примитивные значения и объекты.

### Примитивные типы

Всего в JavaScript семь примитивных типов:

1. `number`
2. `string`
3. `boolean`
4. `bigint`
5. `symbol`
6. `undefined`
7. `null`

> `null` — примитивное значение, хотя `typeof null` возвращает строку `"object"`. Это известная историческая особенность JavaScript.

### Объекты

Всё, что не относится к примитивным значениям, представляет объектную сторону языка. Например:

```js
const user = { name: "Alex" };
const numbers = [1, 2, 3];
function sum(a, b) {
  return a + b;
}
```

Проверка через `typeof` даёт интересный результат:

```js
console.log(typeof user);    // "object"
console.log(typeof numbers); // "object"
console.log(typeof sum);     // "function"
```

Массив остаётся объектом, а для функций `typeof` исторически возвращает отдельную строку `"function"`.

# 3. Number

`number` используется для обычных чисел: целых и вещественных.

```js
const age = 18;
const price = 499.99;
const temperature = -12.5;
```

В JavaScript обычные числа представлены форматом IEEE 754 double precision. На уровне языка не стоит мыслить в терминах «эта переменная занимает ровно столько-то байт»: конкретное хранение — задача движка.

## 3.1. Проверка типа

```js
const n = 5.6;
console.log(typeof n); // "number"
```

Если число записать в кавычках, получится уже строка:

```js
const n = "5.6";
console.log(typeof n); // "string"
```

---

## 3.2. Преобразование строки в число

Есть несколько распространённых способов.

### `Number()`

Пытается преобразовать **всю строку** в число.

```js
console.log(Number("123"));   // 123
console.log(Number(".45"));   // 0.45
console.log(Number(".45w"));  // NaN
console.log(Number("true"));  // NaN
console.log(Number(true));     // 1
console.log(Number(false));    // 0
```

### `parseInt()`

Читает целую часть числа с начала строки.

```js
console.log(parseInt("123"));     // 123
console.log(parseInt("123px"));   // 123
console.log(parseInt("12.8"));    // 12
```

### `parseFloat()`

Читает вещественное число с начала строки.

```js
console.log(parseFloat("12.8"));    // 12.8
console.log(parseFloat("12.8px"));  // 12.8
```

Ключевое отличие: `Number()` ожидает, что всё значение можно трактовать как число, а `parseInt()` и `parseFloat()` могут остановиться на первом неподходящем символе.

# 4. NaN и Infinity

## 4.1. NaN

`NaN` расшифровывается как **Not a Number**. Это специальное числовое значение, которое обычно появляется после неудачной числовой операции или преобразования.

```js
console.log(Number("hello")); // NaN
console.log(typeof NaN);       // "number"
```

Ещё одна особенность:

```js
console.log(NaN === NaN); // false
```

Поэтому для корректной проверки лучше использовать:

```js
console.log(Number.isNaN(NaN));       // true
console.log(Number.isNaN("hello"));   // false
```

Глобальная функция `isNaN()` перед проверкой пытается преобразовать значение в число, поэтому её поведение шире и иногда менее очевидно.

## 4.2. Infinity

`Infinity` означает математическую бесконечность.

```js
console.log(5 / 0);          // Infinity
console.log(-5 / 0);         // -Infinity
console.log(Infinity + 10);  // Infinity
console.log(5 / Infinity);   // 0
```

При неопределённых операциях можно снова получить `NaN`:

```js
console.log(Infinity / Infinity); // NaN
console.log(0 / 0);               // NaN
```

# 5. String

Строка — последовательность символов.

```js
const first = 'hello';
const second = "JavaScript";
const third = `Привет, ${second}!`;
```

В JavaScript используются три варианта записи строк:

- одинарные кавычки: `'...'`;
- двойные кавычки: `"..."`;
- обратные кавычки: `` `...` ``.

Обратные кавычки создают **шаблонную строку**. Она поддерживает подстановку выражений и переносы строк.

```js
const name = "Alex";
const age = 18;

console.log(`Меня зовут ${name}, мне ${age} лет.`);
```

Если внутри строки нужны такие же кавычки, можно использовать другой вид кавычек либо экранирование:

```js
const text = 'Он сказал: "Привет"';
const text2 = "JavaScript — это 'интересно'";
const text3 = "Кавычка: \"";
```

> Размер строки в памяти не стоит вычислять формулой «длина × 2 байта». Спецификация языка не задаёт простой фиксированной формулы хранения строки в памяти.

---

# 6. Boolean

Булев тип содержит только два значения:

```js
true
false
```

Пример:

```js
const isOnline = true;
const isAdmin = false;
```

## 6.1. Truthy и falsy

При преобразовании к `boolean` JavaScript считает ложными следующие основные значения:

```text
false
0
-0
0n
""
null
undefined
NaN
```

Остальные обычные значения — truthy.

```js
console.log(Boolean(1));        // true
console.log(Boolean(-5));       // true
console.log(Boolean(0));        // false
console.log(Boolean(""));       // false
console.log(Boolean(" "));      // true
console.log(Boolean("false"));  // true
console.log(Boolean([]));       // true
console.log(Boolean({}));       // true
```

Строка `"false"` остаётся непустой строкой, поэтому при преобразовании к boolean даёт `true`.

# 7. undefined и null

## `undefined`

Обычно означает, что значение ещё не было назначено.

```js
let result;
console.log(result);        // undefined
console.log(typeof result); // "undefined"
```

## `null`

Обычно используется как явное значение «ничего» или «значение отсутствует».

```js
const selectedUser = null;
console.log(selectedUser);        // null
console.log(typeof selectedUser); // "object"
```

`typeof null === "object"` — историческая особенность языка, а не указание на то, что `null` действительно является объектом.

---

# 8. BigInt и Symbol — пока кратко

Эти типы существуют, но на начальном этапе достаточно понимать их назначение.

## BigInt

Предназначен для целых чисел произвольной точности.

```js
const big = 123456789012345678901234567890n;
console.log(typeof big); // "bigint"
```

`BigInt` нельзя напрямую смешивать с обычным `number` в арифметике:

```js
// 10n + 5 // TypeError
```

## Symbol

Создаёт уникальные значения, которые часто применяются как специальные ключи объектов.

```js
const id = Symbol("id");
console.log(typeof id); // "symbol"
```

Подробно эти типы можно разбирать позже, когда появятся задачи, где они действительно нужны.

# 9. Базовая арифметика

Пусть есть два числа:

```js
const n1 = 5;
const n2 = 2;
```

Основные операции:

```js
console.log(n1 + n2); // 7
console.log(n1 - n2); // 3
console.log(n1 * n2); // 10
console.log(n1 / n2); // 2.5
console.log(n1 % n2); // 1
console.log(n1 ** n2); // 25
```

## Деление нацело

Отдельного оператора целочисленного деления в JavaScript нет. Один из простых вариантов:

```js
console.log(Math.trunc(n1 / n2)); // 2
```

`Math.trunc()` отбрасывает дробную часть.

# 10. Что происходит, если типы разные

JavaScript умеет автоматически преобразовывать типы. Это называется **неявным приведением типов**.

## Number + String

```js
const n = 5;
const s = "2";

console.log(n + s); // "52"
```

Для оператора `+` строка имеет особое значение: если после преобразований один из операндов становится строкой, выполняется конкатенация.

## Другие арифметические операторы

```js
console.log(5 - "2"); // 3
console.log(5 * "2"); // 10
console.log(5 / "2"); // 2.5
```

Операторы `-`, `*`, `/` пытаются получить числовые значения.

Если строка не является числом:

```js
console.log(5 - "true"); // NaN
console.log(5 * "hello"); // NaN
```

## Number + Boolean

При числовом преобразовании:

```text
true  -> 1
false -> 0
```

Поэтому:

```js
console.log(5 + true);  // 6
console.log(5 - false); // 5
```

# 11. Явное и неявное преобразование

## Явное

Мы сами явно указываем, какой тип нужен:

```js
Number(value)
String(value)
Boolean(value)
```

Примеры:

```js
console.log(Number("123")); // 123
console.log(String(123));    // "123"
console.log(Boolean(1));     // true
```

## Неявное

JavaScript выполняет преобразование сам во время операции:

```js
console.log("5" + 2); // "52"
console.log("5" - 2); // 3
```

На практике лучше не рассчитывать на сложное неявное преобразование там, где можно сделать намерение кода очевидным.

```js
const input = "25";
const age = Number(input);
```

Так следующий разработчик сразу понимает, что строка должна быть преобразована в число.

# 13. Что важно запомнить после темы

1. JavaScript имеет семь примитивных типов.
2. `null` — примитив, несмотря на результат `typeof null`.
3. `number` используется и для целых, и для обычных вещественных чисел.
4. `NaN` имеет тип `number`, но не равен самому себе.
5. `Number()`, `String()` и `Boolean()` выполняют явное преобразование.
6. Оператор `+` может складывать числа или объединять строки.
7. `-`, `*` и `/` обычно пытаются привести операнды к числам.
8. `prompt()` в браузере возвращает строку, поэтому числовой ввод почти всегда нужно преобразовывать через `Number()`.
9. Для проверки именно значения `NaN` предпочтительнее `Number.isNaN()`.
10. Если преобразование можно сделать явно и тем самым улучшить читаемость, лучше сделать его явно.

# 14. Небольшие эксперименты для самостоятельной проверки

Перед запуском попробуйте сначала предположить результат.

```js
console.log(typeof null);
console.log(typeof NaN);
console.log(NaN === NaN);
console.log("5" + 2);
console.log("5" - 2);
console.log(Boolean("false"));
console.log(Boolean(""));
console.log(Number("12px"));
console.log(parseInt("12px"));
console.log(0.1 + 0.2);
```

Последний пример связан уже не только с JavaScript, а с представлением вещественных чисел в двоичной форме. К нему удобно вернуться позже как к одной из известных особенностей работы с числами.
