# Простой ввод и вывод в браузере: alert, confirm, prompt

На первых занятиях можно обойтись без HTML-форм и использовать встроенные диалоговые окна браузера.

Эти функции относятся не к самому языку JavaScript, а к браузерной среде (`window`). В Node.js их по умолчанию нет.

## alert()

Показывает сообщение и кнопку подтверждения.

```js
alert('Привет!');
```

Возвращаемого пользовательского значения нет.

## confirm()

Показывает сообщение с двумя вариантами ответа.

```js
const answer = confirm('Продолжить?');
console.log(answer);
```

Возвращает:

- `true`, если пользователь подтвердил действие;
- `false`, если пользователь отказался.

## prompt()

Позволяет ввести строку.

```js
const name = prompt('Введите имя:');
alert(`Привет, ${name}!`);
```

`prompt()` возвращает **строку** либо `null`, если пользователь отменил ввод.

Поэтому числовой ввод нужно преобразовать:

```js
const age = Number(prompt('Введите возраст:'));
console.log(age, typeof age);
```

## Проверка ввода числа

```js
const input = prompt('Введите число:');
const value = Number(input);

if (input === null) {
  alert('Ввод отменён');
} else if (Number.isNaN(value)) {
  alert('Нужно ввести число');
} else {
  alert(`Получено число: ${value}`);
}
```

## Небольшой пример: стоимость заказа

```js
const price = Number(prompt('Цена одного товара:'));
const quantity = Number(prompt('Количество:'));
const total = price * quantity;

alert(`Стоимость заказа: ${total}`);
```

## Небольшой пример с confirm()

```js
const wantsReceipt = confirm('Показать чек?');

if (wantsReceipt) {
  alert('Чек будет показан');
} else {
  alert('Без чека');
}
```

## Важно

`alert`, `confirm` и `prompt` блокируют выполнение страницы, пока окно не будет закрыто. Для учебной демонстрации они удобны, но в реальных интерфейсах обычно используют HTML-формы, кнопки и обработчики событий.
